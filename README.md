# Конкурс идей

Сервис внутренних конкурсов идей: сотрудники подают идеи, затем анонимно голосуют, после чего сервис по расписанию закрывает раунды, раскрывает авторов, определяет победителя и рассылает письма. Организатор в реальном времени видит число идей, число проголосовавших и текущие результаты.

> **Статус: в разработке — завершён этап 0 (подготовка репозитория).** Кода продукта ещё нет. План и статус этапов — [docs/PLAN.md](docs/PLAN.md).

## Предварительные требования

_Будет заполнено на этапе 1._ Основной путь запуска — Docker Compose (Docker Desktop на Windows/macOS или Docker Engine + Compose plugin на Linux); локально устанавливать Python и Node.js не потребуется.

## Переменные окружения

_Будет заполнено на этапах 1 и 5_ (включая `REMINDER_LEAD`: по умолчанию 24 часа, меньшее значение — только для демонстрации).

## Локальный запуск

_Будет заполнено на этапе 1._

## Демонстрационные аккаунты

_Будет заполнено на этапе 1._ Для демо-аккаунтов используется общий публичный пароль — это синтетическое значение, не секрет.

## Запуск тестов

_Будет заполнено на этапе 1._ Все проверки будут запускаться одной командой через Docker.

## Проверка двумя клиентами

Вход хранится в `sessionStorage` — у каждой вкладки браузера свой вход (подробности и компромиссы — [docs/DECISIONS.md, D-003](docs/DECISIONS.md)). Пошаговые сценарии «две вкладки одного пользователя» и «участник и организатор в двух вкладках» будут добавлены на этапах 6–7.
