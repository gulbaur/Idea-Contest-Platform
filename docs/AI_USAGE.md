# Использование AI

## Инструменты и модели

| Инструмент | Модель | Как использовался |
|---|---|---|
| Claude Code (расширение для VS Code) | Claude Opus 5.5 (`claude-opus-5-5`) | Анализ задания, проектирование, написание кода, тестов и документации, запуск проверок. Пользователь принимает решения и проверяет результат по этапам. |

Название инструмента и модели подтверждено пользователем: «Использую Claude Code Opus 5.5» ([PROMPTS.md](PROMPTS.md), запись 2).

## Почему выбраны эти инструмент и модель

Со слов пользователя ([PROMPTS.md](PROMPTS.md), запись 3):

> Claude Code и Opus 5.5 выбрала, потому что уже пользуюсь им и мне удобно работать с файлами проекта и запускать проверки в одной среде. Opus 5.5 использую для разбора требований, планирования, реализации и отладки. Мне важно также получать понятные объяснения решений, чтобы разбираться в проекте

## Как организована работа с агентом

- Работа идёт по этапам из [PLAN.md](PLAN.md); после каждого этапа агент останавливается и ждёт команды.
- Правила работы для агента — [CLAUDE.md](../CLAUDE.md) (сжатая версия исходного промпта).
- Исходный промпт и существенные уточнения — [PROMPTS.md](PROMPTS.md).
- Ход работы с реальными временными отметками — [DEVELOPMENT_LOG.md](DEVELOPMENT_LOG.md).
- Решения и альтернативы — [DECISIONS.md](DECISIONS.md).

## Шаблоны, генераторы и заимствованные решения

| Что | Где использовано | Источник |
|---|---|---|
| Шаблон миграции `script.py.mako` и структура `env.py` Alembic | `backend/migrations/` | Стандартные шаблоны Alembic (`alembic init -t async`), написаны вручную по их образцу и сокращены — https://alembic.sqlalchemy.org/ |
| Официальные Docker-образы `python:3.13-slim`, `postgres:17-alpine` | `backend/Dockerfile`, `compose.yaml` | Docker Hub (официальные образы) |
| Официальные Docker-образы `node:24-alpine`, `nginx:1.28-alpine` | `frontend/Dockerfile` | Docker Hub (официальные образы) |
| Конфигурация Vite (`vite.config.js`, `index.html`) | `frontend/` | Написаны вручную по документации Vite и Vitest; генератор `npm create vite` / `create-vue` не использовался. Значки интерфейса — собственные простые рисунки, сторонний набор значков не использовался |
| Образ `mcr.microsoft.com/playwright/python:v1.58.0-noble` | только для проверки этапа 6 (не в репозитории) | Microsoft Playwright — браузер для ручной проверки интерфейса скриптами во временной папке |

Таблица дополняется при каждом использовании генератора (например, `npm create vite`) или заимствованного решения.
