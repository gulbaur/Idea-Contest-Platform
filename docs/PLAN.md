## Архитектура (кратко)

```
Браузер (Vue SPA) ──HTTP /api, WS /ws──► frontend (nginx: статика + прокси)
                                              │
                                              ▼
                                   backend (FastAPI, 1 процесс)
                                   ├─ REST API
                                   ├─ WebSocket-менеджер (в памяти)
                                   └─ фоновый обработчик расписания (asyncio)
                                              │
                                              ▼
                                        PostgreSQL
```

Сущности БД: `users`, `sessions`, `contests`, `contest_participants`, `ideas`, `votes`, `jobs`, `emails`.
Продуктовые правила и решения — [DECISIONS.md](DECISIONS.md). Матрица требований — [REQUIREMENTS.md](REQUIREMENTS.md).
